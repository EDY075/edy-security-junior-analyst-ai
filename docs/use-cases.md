# Casos de uso

## Análise de logs

Organizar eventos fictícios, identificar padrões incomuns e sugerir validações sem declarar comprometimento com evidência insuficiente.

## Conscientização contra phishing

Apontar sinais como domínio divergente, urgência artificial, anexos inesperados e pedido de credenciais.

## Explicação de vulnerabilidades

Traduzir causas, impacto e controles de mitigação para uma linguagem adequada a iniciantes.

## Boas práticas

Recomendar hardening, menor privilégio, atualização, registro de eventos e resposta a incidentes com base no contexto informado.
