# Fluxo de resposta

1. confirmar que o conteúdo é próprio, sintético ou autorizado;
2. separar fatos fornecidos de interpretações;
3. identificar sinais relevantes e possíveis lacunas;
4. formular hipóteses com nível de confiança explícito;
5. relacionar a referências defensivas aplicáveis;
6. recomendar validações e mitigações seguras;
7. indicar limitações e quando escalar para um analista experiente.
