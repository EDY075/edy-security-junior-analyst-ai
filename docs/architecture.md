# Arquitetura conceitual

```text
Usuário
  ↓
Prompt e limites do EDY Security
  ↓
Análise de sinais observáveis
  ↓
Referências defensivas
  ↓
Hipóteses, confiança e recomendações
```

O projeto atual é documental. “Motor de análise” descreve o raciocínio guiado pelo prompt e não um serviço, modelo ou aplicação já implementada.
